BAR CAFE — المنيو الرقمي + QR كود
===================================

ملفات المشروع:
--------------
1) index.html       ← صفحة المنيو الرقمية (عربي / English)
2) qr-card.html     ← كارت QR جاهز للطباعة (الكود شغّال الآن!)
3) qr-print.html    ← صفحة توليد QR كود جديد لأي رابط وطباعته
4) qrcode.min.js    ← مكتبة الـ QR (مطلوبة لتوليد الكود)
5) qr-barcafe.png   ← صورة QR (1968×1968 بكسل) — الأفضل للطباعة والواتساب
6) qr-barcafe.svg   ← QR كملف فيكتور (مقاسات غير محدودة)
7) qr-barcafe.gif   ← QR كملف GIF صغير (توافق عام)
8) README.txt       ← الملف ده

---------------------------------------

---------------------------------------
الخطوة 1: رفع المنيو على استضافة دائمة (اختياري لكن الأفضل)
---------------------------------------
عشان الـ QR يشتغل لازم صفحة المنيو تكون على النت (مش على جهازك).

الطريقة الأسرع — Netlify Drop (مجاني ودائم):
1) افتح المتصفح وادخل:  https://app.netlify.com/drop
2) اسحب مجلد "BAR CAFE" كله (الملفات الستة) وحطه في الصفحة
3) استنى ثواني هتاخد رابط زي:
      https://random-name-123.netlify.app
4) صفحة المنيو بتاعتك هتكون:
      https://random-name-123.netlify.app/index.html

*** ملاحظة: المنيو الحالي مرفوع بالفعل على GitHub Pages (دائم)،
    فمش محتاج Netlify إلا لو حبيت تزود رابط ثاني. ***

طريقة تانية — GitHub Pages (مجاني ودائم):
1) اعمل مستودع (Repository) جديد باسم مثلا cafe-menu
2) ارفع الملفات في المستودع
3) من Settings > Pages اختر main branch وحفظ
4) رابط المنيو:  https://اسمك.github.io/cafe-menu/index.html

بعد ما تاخد الرابط الدائم:
- افتح ملف qr-card.html وحوّل رابط MENU_URL للرابط الجديد
- أو افتح qr-print.html وحط الرابط واضغط توليد ثم طباعة
- واطبع الكارت الجديد

---------------------------------------
الخطوة 2: طباعة كارت الـ QR
---------------------------------------
1) افتح ملف  qr-card.html  في أي متصفح
2) اضغط "طباعة الكارت" أو Ctrl+P
3) علّق الكارت على الترابيزات أو على باب الكافيه
   — أي عميل يمسحه بموبايله هيوصله المنيو مباشرة 📲

---------------------------------------
كيف تعدّل الأصناف والأسعار؟
---------------------------------------
افتح ملف index.html بأي محرر نصوص.
اسحب لتحت لحد ما توصل لقسم MENU اللي شكله كده:

      const MENU = [
        {
          e: "☕", ar: "القهوة الساخنة", en: "Hot Coffee",
          items: [
            { ar: "إسبريسو", en: "Espresso", price: 40 },
            ...
          ]
        },
        ...
      ];

تعديل سعر:  غيّر الرقم بعد price:
      { ar: "إسبريسو", en: "Espresso", price: 50 }  ← غيّرت السعر

صنف بمقاسات M / L (اكتب السعر كنص بين علامتي اقتباس):
      { ar: "كابتشينو", en: "Cappuccino", price: "M: 50 | L: 70" }

إضافة وصف / المكونات:  استخدم desc:
      { ar: "موكا", en: "Mocha", price: 80, desc: "إسبريسو + شوكولاتة + حليب" }

إضافة "إضافات" لصنف معين:  استخدم extra (قائمة عربي/إنجليزي):
      { ar: "مولتن كيك", en: "Molten Cake", price: 80,
        extra: [
          { ar: "إضافة صوص: +10", en: "Add sauce: +10" },
          { ar: "إضافة بستاشيو: +25", en: "Add pistachio: +25" }
        ] }

إضافة صنف جديد جوه فئة موجودة:  انسخ أي سطر { ar:.., en:.., price:.. } وعدّله.

إضافة فئة جديدة كاملة:  انسخ أي كتلة { e:.. ar:.. en:.. items:[...] } وعدّلها.
ولو عند الفئة "إضافات" عامة (زي بوبا / ويب كريم)، زود:
      note: [ { ar: "إضافة بوبا: +30 ج.م", en: "Add boba: +30 EGP" } ]

---------------------------------------
كيف تعدّل اسم الكافيه / التليفون / الواتساب؟
---------------------------------------
في نفس الملف، فوق قسم MENU هتلاقي:

      const CAFE = {
        phone: "01098396937",
        whatsapp: "201098396937",
        currency: "ج.م",
        currencyEn: "EGP"
      };

- phone: الرقم اللي يظهر في الصفحة
- whatsapp: رقم الواتساب اللي يستقبل الطلبات
  (بصيغة دولية بدون + أو أصفار في الأول مثلا: 201XXXXXXXXX)
- currency: العملة بالعربي (ج.م) — currencyEn: العملة بالإنجليزي (EGP)

بعد أي تعديل: احفظ الملف وارفع النسخة الجديدة على Netlify مرة تانية
(اسحب المجلد من جديد على نفس الموقع) — الرابط هيبقى ثابت ما دمت
مسجّل دخول بنفس الحساب.

---------------------------------------
لماذا الـ QR دائم ولا "يخلص" أبداً؟ (مهم)
---------------------------------------
1) الـ QR بتاعنا "static" (كود صامت) — يعني الصورة نفسها
   محفور فيها الرابط مباشرة، من غير أي وسيط أو مدة صلاحية.
   QR مش بيخلص و مش بينتهي — بيشتغل طول ما الرابط شغال.
   (اللي "بيخلص" هو QR ديناميكي من مواقع بتطلب فلوس —
   إحنا مش شغالين بكده خالص.)

2) الاستضافة على GitHub Pages أحد متصفح GitHub نفسه:
   - مجانية للأبد للأكواد العامة (المستودع ده عام ✅)
   - مالهاش تاريخ انتهاء — الموقع فضال طول ما المستودع موجود
   - حدودها ضخمة (100 جيجا تحميل في الشهر) والموقع ده صغير جداً

3) 3 نسخ احتياطية محفوظة:
   - المجلد على سطح المكتب (نسخة العمل)
   - المستودع على GitHub (نسخة السحابة)
   - الـ git المحلي بيسجل كل التعديلات

خطر واحد بس في الدنيا: لو الحساب نفسه اتمسح/ضاع.
الحل لو ده حصل (10 دقايق بس):
   - المنيو كله في ملف واحد (index.html) — ارفعه لأي استضافة
     مجانية (Netlify/Cloudflare) من نفس الرابط بتاع المجلد
   - افتح qr-card.html وغيّر سطر واحد:
        var MENU_URL = "الرابط الجديد";
   - افتح qr-print.html → توليد → طباعة الكارت الجديد
   - باقي الملفات (الأسعار/الإضافات) كلها في index.html نفسه
